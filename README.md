# DUAL Draw

Programa de dibujo para **dos teléfonos que funcionan como uno** (sistema ChronOS): arriba (principal) la obra
completa con paneles fijos de color y capas; abajo (extendido) el lienzo con zoom, pinceles y herramientas.
También funciona en un solo teléfono. Descarga: `DualDraw.apk` en Releases.
